# 데이터 안내

원 분석에는 인구 격자, 행정경계, 편의점, 버스정류장과 기존 수거함 관련 자료를 사용했습니다. 구체적인 출처와 기준 시점은 보고서의 데이터 표와 참고문헌에 정리되어 있습니다.

SGIS 원본과 원천 자료 전체는 이 저장소에 재배포하지 않습니다. 각 제공기관의 이용조건에 따라 자료를 확보하고 `code/data/`에 배치해야 합니다. API를 사용하는 셀이 있다면 본인의 인증정보를 환경변수로 관리하세요.

공개한 `results/scenario_summary.csv`는 원 분석에서 저장한 집계 결과입니다. 원자료나 사람별 기록이 아닙니다.
