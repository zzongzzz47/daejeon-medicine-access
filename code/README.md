# 사용한 코드

## 읽는 순서

1. `데이터 전처리.ipynb`: 원본 통계와 공간 자료 정리
2. `위치정보.ipynb`: 대상 지역과 후보 위치 확인
3. `클러스터링_스코어링.ipynb`: 후보 특성 구성과 점수화
4. `수요지 만들기.ipynb`: 수요지와 가중치 구성
5. `최적화.ipynb`: 거리와 시설 수별 최대 커버링 분석
6. `기존 수거함.ipynb`: 기존 시설의 별도 비교

독립적인 탐색 셀이 포함된 원 분석 노트북입니다. 위 순서가 모든 셀을 자동 연결하는 파이프라인을 뜻하지는 않습니다. 원본의 파일 경로와 중간 결과를 확인하며 실행해야 합니다.

```sh
cd code
python -m pip install -r requirements.txt
python -m jupyterlab
```

노트북에서 사용하는 `./data/` 아래에 원본 자료와 중간 파일을 준비하세요. 로컬 절대 경로가 남아 있는 입력 셀은 본인 환경에 맞춰 수정합니다. 재실행보다 결과 확인이 목적이라면 `../reports/`와 `../results/`를 먼저 보세요.
